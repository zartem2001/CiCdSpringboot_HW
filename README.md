# TODO-лист с CI/CD пайплайном и деплоем на VM

## 📋 Описание задачи

Разработать Spring Boot приложение с REST API для управления задачами (TODO-лист) 
и настроить полный **CI/CD пайплайн** с автоматическим деплоем на виртуальную машину.

## 🎯 Цель

Отработать:
- Создание REST API на Spring Boot;
- Написание unit-тестов с покрытием ≥ 70%;
- Настройку **GitHub Actions** для CI/CD;
- Многостадийную сборку **Docker**-образа;
- Деплой на виртуальную машину через SSH;
- Безопасную работу с секретами.

## 🛠️ Используемые технологии

- Java 17+
- Spring Boot (Spring Web, Spring Validation)
- Docker
